دليل التركيب بالعربي

Install in a few steps

  1. Install Dynamic Island Pro 2.6.1 or newer on Windows 10/11 x64. Get the free installer from official releases. If 2.6.1 is not published yet, wait for that release; older versions cannot import this pack.
  2. Extract this ZIP to a folder. Open Settings → Personalize → Export setup and save my-island-before-supporter.json somewhere safe. This backup contains preferences, profiles, bookmarks and world clocks, not a full backup of notes or other app data.
  3. Choose Import setup and select supporter-all.json. This adds all six layouts without activating one. Your existing profiles, shortcuts, world clocks, notes, pinned apps, Quran favorites and current settings stay in place.
  4. Under Saved profiles, choose Apply beside a Supporter profile. Applying changes colors, dimensions, motion and tab layout only. It leaves privacy settings, reminders, audio feedback and timer durations as you set them. All ten tabs remain available.
  5. To switch, apply another saved profile. To restore your earlier preferences, import the backup from step 2. A full backup replaces the preferences/profiles/bookmarks/clocks it contains, including later edits. Notes and pinned apps are not replaced.
Not enough profile slots? The app holds 12 profiles. Each new layout needs one free slot. Import a single file from profiles/ instead, or export your setup before deleting profiles you no longer need. A conflicting name or full library cancels the entire pack import. Importing the exact same pack again adds no duplicates.

تركيب الباقة

  1. استخدم Dynamic Island Pro إصدار 2.6.1 أو أحدث على ويندوز 10 أو 11 بنظام 64 بت. البرنامج مجاني من رابط الإصدارات الرسمي فوق. لو الإصدار لسه مش منشور، استنى نزوله؛ الإصدارات الأقدم مش بتدعم الباقة.
  2. فك ضغط الباقة. من Settings ← Personalize ← Export setup احفظ نسخة من إعداداتك قبل التغيير. النسخة دي بتحفظ التخصيص والبروفايلات والاختصارات والساعات، ومش نسخة احتياطية كاملة لملاحظاتك وباقي بيانات البرنامج.
  3. اضغط Import setup واختار supporter-all.json. الست بروفايلات هتتضاف من غير تفعيل تلقائي، ومن غير حذف إعداداتك أو ملاحظاتك أو اختصاراتك أو مفضلة القرآن.
  4. من Saved profiles اضغط Apply جنب البروفايل اللي يعجبك. التغيير للشكل وترتيب الأدوات فقط. الخصوصية والتنبيهات وأصوات التفاعل ومدد المؤقت بتفضل زي ما ظبطتها، وكل التبويبات متاحة.
  5. للرجوع، استورد النسخة الاحتياطية اللي حفظتها. استرجاع النسخة بيستبدل التخصيص والبروفايلات والاختصارات والساعات بالمحفوظ فيها، بما فيها أي تعديلات عملتها بعدها؛ ملاحظاتك والتطبيقات المثبتة مش بتتغير.
الحد الأقصى 12 بروفايل. لو المساحة مش كفاية، استورد ملف واحد من مجلد profiles/، أو صدّر إعداداتك قبل حذف بروفايلات قديمة. تعارض الأسماء أو امتلاء القائمة بيلغي الاستيراد كله. استيراد نفس الباقة تاني مش بيكرر البروفايلات.

بروفايلات الشغل الهادي والاجتماعات بتغيّر الشكل والحركة؛ مش بتكتم التنبيهات ومش بتخفي بياناتك وقت مشاركة الشاشة. الخلفية والملفات التجريبية في الصور مش ضمن الباقة.
